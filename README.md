#Mufy Recap

看你的 Mufy 互动数据的玩具一个。
不用装复杂的后端，纯前端运行，极简黑白灰UI。

## 核心功能
为你精准生成“你老公（角色榜）”和“你婆婆（作者榜）”
大于1k轮也可以抓取看到具体轮数而不是概括
支持楼中楼评论递归抓取，哪怕藏在深处也能揪出真实互动轮数。
已失效的卡会被无情展示“你两见过，没嫖过，你也嫖不了了”。
点击右上角 相机，一键隐藏所有按钮！
扫描期间无法跳转，安心等待进度条拉满。

## 安装与使用
1. 确保你的浏览器安装了 [Tampermonkey（油猴）](https://www.tampermonkey.net/)。
2. 在本页面点击 `mufy-recap.user.js`，然后点击 `Raw`，或者直接前往 [GreasyFork]搜索mufy一键安装。
3. 打开 Mufy 网页，点击右下角的 `✦` 即可启动。

>  声明：本脚本仅供交流学习，抓取的数据仅保存在你本地浏览器的缓存中。
