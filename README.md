# Mufy Recap 1.0

**看你的 Mufy 互动数据的玩具一个。**

## 核心功能
- 为你精准生成「你老公（角色榜）」和「你婆婆（作者榜）」
- 大于 1k 轮也能抓到具体轮数，而不是给你一句"很多"
- 支持楼中楼评论递归抓取，藏在最深处的真实互动轮数也能揪出来
- 已失效的卡会被无情展示「你两见过，没嫖过，你也嫖不了了」
- 点击右上角相机，一键隐藏所有按钮，纯净截图
- 扫描期间无法跳转，安心等进度条拉满
- 支持粘贴角色链接 / ID 单独查询某个角色的轮数

## 安装与使用
1. 确保浏览器装了 [Tampermonkey（油猴）](https://www.tampermonkey.net/)
2. 在本页面点 `mufy-recap.user.js` → `Raw`，或直接去 [GreasyFork] 搜 mufy 一键安装
3. 打开 Mufy 网页，点右下角 `✦` 启动

> 声明：本脚本仅供交流学习，抓取的数据仅保存在你本地浏览器的缓存中。

# Mufy Recap 2.0

**1.0 是玩具，2.0 是工具。**

从"看你聊了多少"进化成"帮你把 Mufy 玩得更省事"——数据统计保留，另外塞进一整套收藏、面具、收割、多开的自动化。

## 保留的老本行（1.0 全功能）
- 角色榜 / 作者榜、>1k 轮精准轮数、楼中楼递归抓取
- 失效卡吐槽、纯净截图、单角色查询、本地缓存

## 新增功能

**收藏管理**
- 按作者分组，一键收藏某作者名下全部未收藏角色
- 自动为每个作者创建 / 复用收藏夹，把角色批量塞进去，顺手设个封面
- 已藏 / 未藏筛选，一键整理全部

**面具库**
- 本地面具预设库，随时激活到官方槽位
- 槽位满了？选一个替换，被替换的仍留在本地库，随时能换回来
- 给具体角色绑定面具，进聊天页自动切过去

**主页收割机**
- 自动翻页抓主页推荐角色，批量收藏
- 可选自动发打招呼，且会先拉历史记录，跳过已聊过的角色，不浪费对话额度
- 发送间隔随机化，别那么像机器人

**多账号管理**
- 保存多个账号 Token，一键批量"唤醒签到"（利用活跃即签到机制）
- 一键切换账号，自动清理残留缓存，避免认错人
- 赛博账本：统计今日 / 累积的猫粮、罐头、打赏、鱼干收支流水

**其他**
- 榜单内搜索角色 / 作者
- 单角色刷新按钮，不用整轮重扫
- 全部数据存本地，依旧零权限、零后端

## 安装与使用
1. 确保浏览器装了 [Tampermonkey（油猴）](https://www.tampermonkey.net/)
2. 在本页面点 `mufy-recap.user.js` → `Raw`，或直接去 [GreasyFork] 搜 mufy 一键安装
3. 打开 Mufy 网页，点右下角 `✦`，顶部标签切到你想用的功能

> 声明：本脚本仅供交流学习，抓取的数据仅保存在你本地浏览器的缓存中。
